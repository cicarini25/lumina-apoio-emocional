# lumina-apoio-emocional
Aplicativo web full-stack de apoio emocional com IA , escuta ativa , comunidade segura, chat interativo ,biblioteca de bem estar ,autenticação protegida e recursos de privaciodade .
É uma plataforma digital acolhedora criada para oferecer escuta ativa ,orientação emocional e acompanha em momentos difíceis;
O projeto reúne uma assistente virtual de IA empática ,comunidade segura com anonimato opcional ,chat interativo etc..
A Lumina não substitui profisionais da saúde ,seu propósito é oferecer acolhimento ,reflexão e incentivo a busca de ajuda adequada quando necessário.
